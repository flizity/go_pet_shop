#  Go Pet Shop V3

## 📝 Описание

**Go Pet Shop V3** — третья версия API/сервиса для управления зоомагазином на Go. В этой версии реализованы новые функции, улучшена производительность, расширены возможности интеграции и обеспечена повышенная безопасность.

## 🚀 Возможности

- 📦 Продвинутое управление товарами: категории, фильтры, изображения
- 🛒 Продвинутое управление заказами: статусы, история, уведомления
- 👤 Улучшенная работа с пользователями: профили, права доступа, отчёты
- 🐕 Работа с питомцами: расширенные атрибуты, медицинские карты
- 🔌 Встроенные интеграции с платёжными системами и CRM
- ⚙️ Поддержка асинхронных задач и очередей
- 🛡️ Расширенная авторизация и аутентификация (OAuth, JWT)
- 📊 Метрики и мониторинг

## ⚡️ Установка

```bash
git clone https://github.com/flizity/go_pet_shop.git
cd go_pet_shop/v3
go mod tidy
go run main.go
```

## 📖 Использование

После запуска приложение будет доступно по адресу `http://localhost:8080`.  
Документация по эндпоинтам API доступна в файле `docs/api_v3.md`.

## 📂 Структура проекта

- `main.go` — точка входа в приложение
- `internal/` — бизнес-логика, сервисы, интеграции
- `api/` — обработчики HTTP-запросов
- `models/` — структуры данных
- `docs/` — документация
- `config/` — настройки приложения

## 💡 Пример запроса

```bash
curl -X POST http://localhost:8080/api/v3/pets -d '{"name":"Kitty","type":"cat","medical_card":{...}}'
```

## 🔄 Отличия от V2

- Переработанная архитектура: поддержка микросервисов и асинхронности
- Расширение возможностей API: новые сущности и атрибуты
- Улучшения интеграций: платёжные системы, уведомления, CRM
- Повышенная безопасность: OAuth, JWT, шифрование данных
- Метрики и мониторинг для стабильной работы
