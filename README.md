#  Go Pet Shop V2

## 📝 Описание

**Go Pet Shop V2** — это вторая версия API/сервиса для управления зоомагазином, реализованная на языке Go. В этой версии улучшена архитектура, расширена функциональность и повышена стабильность работы по сравнению с первой версией.

## 🚀 Возможности

- 📦 Управление товарами: добавление, редактирование, удаление, просмотр
- 🛒 Управление заказами: создание, обновление, отмена, просмотр статуса
- 👤 Управление пользователями: регистрация, авторизация, роли
- 🔗 API для интеграции с внешними сервисами
- 📝 Логирование и обработка ошибок

## ⚡️ Установка

```bash
git clone https://github.com/flizity/go_pet_shop.git
cd go_pet_shop/v2
go mod tidy
go run main.go
```

## 📖 Использование

После запуска приложение будет доступно по адресу `http://localhost:8080`.  
Документация по эндпоинтам API доступна в файле `docs/api_v2.md`.

## 📂 Структура проекта

- `main.go` — точка входа в приложение
- `internal/` — бизнес-логика и сервисы
- `api/` — обработчики HTTP-запросов
- `models/` — структуры данных
- `docs/` — документация

## 💡 Пример запроса

```bash
curl -X POST http://localhost:8080/api/v2/pets -d '{"name":"Doggy","type":"dog"}'
```

## 🔄 Отличия от V1

- Переписана архитектура для лучшей масштабируемости
- Добавлены новые сущности (категории, отзывы)
- Улучшена система авторизации
- Добавлены интеграции с внешними сервисами
